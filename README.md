# Screen Reader Virtual Cursor Simulator (Seed)

This is a seed scaffold containing:
- `/AGENTS.md` — code ownership and workflow
- `/spec` — behavioral and architectural specs
- `/INITIAL_PROMPT.md` — initial Codex prompt to generate the extension code

## How to use
1. Unzip into an empty repo.
2. Paste `INITIAL_PROMPT.md` into Codex.
3. Let Codex generate the MV3 extension implementation aligned with `/spec`.
